# Touch Pad UCI page

A ready-to-import Q-SYS UCI page for the **Nikita Touch Pad** plugin: one page,
1280 × 800, for a 500 × 500 pad at (78, 112), styled for the Perfect Pitch
"Sunset" UCI style.

| File | What it is |
|---|---|
| `TouchPad-Page.uci` | the UCI bundle to import |
| `TouchPad-Page.json` | the page specification it was generated from (geometry, pins, classes, colours, script) |
| `TouchPad-Page.svg` | a layout sketch of the page (positions and sizes only, not the real rendering) |

## What is on the page

Layer `TouchPad` on page `Touch Pad`, page colour `#120B08`:

| Element | Rectangle | Notes |
|---|---|---|
| Cover group box | (38, 98) 959 × 528 | page-coloured (`#120B08`), no stroke, no radius; hides the Color Picker surface |
| Pad placeholder group box | (78, 112) 500 × 500 | Sunset pad colour `#120B08`, 1 px `#45301F` line, radius 18; the three Display copies go exactly here |
| Instruction text | (94, 318) 468 × 88 | "TOUCH PAD: drop the Color Picker surface under the cover, then paste the plugin's Display here 3 times"; delete it when done |
| `CAMERA` label | (1020, 84) 220 × 20 | class `pp-section-label` |
| Home / Zoom In / Zoom Out | (1020, 112 / 200 / 288) 220 × 72 | momentary buttons, class `pp-ptz` + icon class |
| Flip Pan / Flip Tilt / Lock / Calibrate | (1020, 376 / 464 / 552 / 640) 220 × 72 | toggle buttons, class `pp-cam` |
| `Gesture` readout placeholder | (78, 644) 500 × 56 | text block, class `pp-hint`; replace with a Text Box linked to the plugin's Gesture pin |
| Brand line | (1000, 764) 240 × 24 | "Nikita Visual Arts – nikitavisual.art", 13 px, `#C7AE9C` |

The geometry follows the plugin's rule for a pad whose longer side is P = 500:
the Color Picker surface is ceil(1.91 × P) = 955 wide and P + 24 = 524 tall; the
pad's top-left sits round(0.04 × 955) = 38 px to the right and 12 px below the
picker's top-left; the cover is the picker rectangle grown by 2 px on each side.
With the picker at (40, 100) that gives the pad at (78, 112) and the cover at
(38, 98) 959 × 528.

## Import

1. Install the plugin and drop a **Nikita Touch Pad** block into the design.
2. Create a **new, empty UCI** in the design (Design Elements → User Control
   Interfaces). *Tools → Update UCI From Bundle* is greyed out until a UCI
   exists.
3. Select that UCI, choose **Tools → Update UCI From Bundle** and pick
   `TouchPad-Page.uci`.
4. The seven `TP_` controls show as **unlinked** after import. That is the
   normal state of a freshly imported bundle, not a fault; wire them as
   described below.
5. In the UCI's properties turn **Swipe Disabled** on (see below).

## Two things you must add by hand

The bundle cannot carry them, so the page provides everything around them:

**The Color Picker surface.** The pad reads touches from the plugin's native
Color Picker. Drag the plugin's Color Picker control from the plugin block
onto the page, set it to position (40, 100) and size 955 × 524, and move it
**below** the cover group box in the layer order so the cover hides it. The
bundle was generated by cloning element prototypes out of an exported
template, and that template contains no Color Picker, so there was nothing to
clone.

**The pad's drawing: three copies of the plugin's Display control.** The
Display control has no pin; it is dragged from the plugin block, never wired.
A control that is not a pin on the UCI's controller component cannot be
generated into a bundle, so paste it by hand: copy the plugin's Display
control, paste it three times, and give every copy position (78, 112) and size
500 × 500, on top of the pad placeholder group box. Then delete the instruction
text block. The plugin draws through the three stacked copies.

## Pins to wire

The bundle's buttons are pins on the **UCI's controller component**
(the UCI script component named after the UCI). Wire each to the plugin:

| UCI button | UCI pin | Type | Plugin pin |
|---|---|---|---|
| Home | `TP_Home` | momentary | Home |
| Zoom In | `TP_ZoomIn` | momentary | Zoom In |
| Zoom Out | `TP_ZoomOut` | momentary | Zoom Out |
| Flip Pan | `TP_FlipPan` | toggle | Flip Pan |
| Flip Tilt | `TP_FlipTilt` | toggle | Flip Tilt |
| Lock | `TP_Lock` | toggle | Lock |
| Calibrate | `TP_Calibrate` | toggle | Calibrate |

The UCI script is a comment only: nothing on this page needs Lua, the pins do
the work.

## Swipe Disabled

Turn **Swipe Disabled** on in the UCI's properties, otherwise a drag across
the pad can be taken as a page swipe. The bundle carries the flag from the
template it was built on, but *Update UCI From Bundle* applies a bundle to an
existing UCI, so check the property after import rather than assume it.

## Style

The page was generated from the Perfect Pitch meeting-room template and
assumes its CSS UCI style **PerfectPitch** ("Sunset": espresso background,
sunset accents). The classes it uses are `pp-ptz` with `pp-ptz-home`,
`pp-ptz-zoom-in`, `pp-ptz-zoom-out` (momentary buttons), `pp-cam` (toggle
buttons), `pp-section-label` (the CAMERA label) and `pp-hint` (the Gesture
placeholder). The style's CSS and its files (`fonts/Heebo-Regular.ttf`,
`fonts/Heebo-SemiBold.ttf`, `fonts/Heebo-Bold.ttf`, `fonts/PPIcons.ttf`,
`images/bg-landscape.png`) are embedded in the bundle as the template exported
them, and the style is also expected in Designer's Styles folder
(`Documents\QSC\Q-SYS Designer\Styles\PerfectPitch`). Without the style the
buttons and labels fall back to Designer's default look; the cover, the pad
placeholder and the text colours are set on the elements themselves and do
not depend on it. Note that the style's `page` rule paints
`images/bg-landscape.png` (with the Perfect Pitch logo top-left) behind
every page; remove that rule from the style, or use another style, if the
Touch Pad page should not show it.

## Limits

- The bundle was generated from the specification with a file toolkit and
  checked only with that toolkit's structural checks: the record stream
  validates, the file round-trips, every control's spec, control value and
  controller config agree, the layer is visible, and the layout sketch matches
  the specification. **It was never imported into Q-SYS Designer by us.** If
  Designer refuses the file or shows an element wrongly, that observation
  outranks these checks.
- Designer version compatibility follows the template: it was exported by
  Q-SYS Designer **10.5.0.0** and that assembly version is embedded in the
  file. A file written for 10.5 is not guaranteed to load in an older
  Designer.
- `TouchPad-Page.svg` is a layout sketch in the toolkit's own colours. It
  shows where things are, not how the style renders them.
- The template provided button, fader, group box, text and media-display
  prototypes only. There is no text-box prototype, which is why the Gesture
  readout is a placeholder text block, and no Color Picker prototype, which is
  why the picker surface is added by hand.
